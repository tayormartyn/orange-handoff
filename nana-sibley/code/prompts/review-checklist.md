# Human Review Gate — quality checklist

> Run this on every generated script before it is voiced or rendered, at
> least until the engine has earned your trust. Your counselling ear on the
> "turn" beat is the differentiator — keep it in the loop.

## Rule Zero
- [ ] No line implies the character is a real living person.
- [ ] Nothing framed as therapy, diagnosis, treatment, or a fixed prediction.
- [ ] Symbols/cards/palms presented as mirrors, with hedged language.

## Safety
- [ ] If the input hinted at crisis/self-harm/abuse → `safety_flag` is true,
      no reading was produced, and the care message is warm and non-clinical.

## Voice & character
- [ ] Sounds like the *specific* character, not generic AI-nice.
- [ ] Correct lexicon, endearments, and the right opening + closing ritual.
- [ ] No banned words (wellbeing, journey, subscribe, guys, manifest, …).
- [ ] Written for the breath (pauses land; you don't run out of air reading it).

## Craft
- [ ] Validation comes *before* any insight or symbol.
- [ ] Exactly one core idea (Nan/Maeve) or one small action (Jesse).
- [ ] Ends by returning agency (open question or one doable step).

## Format & output
- [ ] Follows the format's beats and target length.
- [ ] Valid JSON matching the schema; editor notes present.
- [ ] Folklore is generic old-country, not tied to a real ethnic group.

**If any box fails → regenerate or edit before it goes near a render.**
