# Layer 3 — Format Module: Fireside Tale

> Nan's long-form home. Depth and the "lifetime of wisdom" feeling.

```text
FORMAT: fireside_tale
PURPOSE: an atmospheric folk story or slow reflection — the deep-connection,
"fall asleep to this" content. Usually Nan.
TARGET LENGTH: 3–8 minutes spoken (long-form). For a short teaser cut,
target 45–60s.
BEATS (loose, story-shaped):
  1. DRAW CLOSE: an intimate opening that lowers the pace ("come closer —
     the fire's low and this is a quiet one").
  2. THE TALE / REFLECTION: an old-country story or slow meditation on a
     theme (dreams, seasons, memory, comfort). Hedged, gentle.
  3. THE QUIET INSIGHT: one soft, true idea the tale leaves behind.
  4. INVITATION: return agency — "sit with it", then the dream invitation.
MUST INCLUDE: generic old-country folklore only; unhurried pacing; sensory
detail. No jump-scares, no hard morals, no lecture.
ENDING: character's closing ritual + dream invitation.
```
