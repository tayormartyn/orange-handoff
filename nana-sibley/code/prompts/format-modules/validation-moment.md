# Layer 3 — Format Module: Validation Moment

> The attachment builder. Pure warmth, no "lesson". This is the share-magnet.

```text
FORMAT: validation_moment
PURPOSE: make the viewer feel seen and held — no symbol, no teaching, just
presence. Builds love and loyalty.
TARGET LENGTH: 25–35 seconds spoken (~65–90 words).
BEATS (in order):
  1. NOTICE: see the one person watching ("you've had one of those days,
     haven't you"). 
  2. PERMISSION / VALIDATION: legitimise the feeling; remove the pressure
     to explain or fix it.
  3. A SMALL TRUE THING: one gentle reframe or piece of permission (e.g.
     "just the next hour, then the hour after").
  4. QUIET CLOSE: a soft blessing + the door left open.
MUST INCLUDE: no advice-giving, no symbol, no lesson stacked on top.
Exactly one feeling, one comfort.
ENDING: soft — the character's closing ritual, gently. Dream invitation
optional/underplayed here.
```
