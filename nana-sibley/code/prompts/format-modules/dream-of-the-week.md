# Layer 3 — Format Module: Dream of the Week

> The flywheel feature. Reads ONE submitted dream as the weekly highlight.

```text
FORMAT: dream_of_the_week
PURPOSE: feature one submitted dream (anonymised + consented) as the weekly
event that drives comments and returns.
TARGET LENGTH: 40–75 seconds spoken.
PRECONDITION: run the SAFETY LAYER on the submission first. If flagged,
DO NOT produce this — set safety_flag and stop.
BEATS (in order):
  1. WARM INTRO: thank the person for trusting us with it (the human first).
  2. READ IT BACK: briefly restate the dream with care (reflective
     listening) — the dreamer should feel heard.
  3. VALIDATE THE FEELING: name what they likely felt; normalise it.
  4. MIRROR (LORE): offer the old-country symbol as a mirror, hedged.
  5. HAND IT BACK: one gentle open question. Agency stays with them.
  6. INVITE NEXT WEEK: thank them by first name (with permission), invite
     new submissions for next week.
MUST INCLUDE: anonymity respected; "some say"; the four-beat reply craft.
ENDING: "leave yours below — next week it could be your dream by the fire."
```
