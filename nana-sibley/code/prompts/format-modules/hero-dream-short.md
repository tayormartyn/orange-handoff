# Layer 3 — Format Module: Hero Dream Short

> The workhorse. Inject as the FORMAT for a 40-second dream-symbol reading.

```text
FORMAT: hero_dream_short
PURPOSE: the signature discovery format — name a common dream, give the
old-country meaning as a mirror, turn it into one gentle self-reflection,
comfort, invite.
TARGET LENGTH: 35–45 seconds spoken (~90–120 words).
BEATS (in order, one per beat):
  1. HOOK (0–2s): name the exact dream in the first breath so the right
     viewer stops. No intro, no logo, no greeting.
  2. LORE (2–8s): "some say…" the old-country meaning. Warm, hedged.
  3. TURN (8–28s): move from symbol to self — ONE gentle reflective
     question about the viewer's waking life. (This is the counselling
     "turn" — validate, then invite reflection.)
  4. COMFORT (28–36s): a warm, resolving, non-scary line.
  5. INVITE (36–42s): the character's closing ritual + dream invitation.
MUST INCLUDE: hedged language ("some say"); a disclaimer_line where a
symbol/card/palm is used; validation before the turn.
ENDING: character's closing ritual + "leave your dream / I read one every
week."
```
